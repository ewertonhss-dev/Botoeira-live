# Botoeira de Sons 5×10

Versão com edição bloqueada por padrão.

## Funcionamento
- Fora do modo de configuração, clicar nos botões apenas reproduz o áudio.
- Botões vazios não abrem a tela de upload.
- Clique em **Configurar** para liberar a edição dos 50 botões.
- Durante a configuração, clique em qualquer botão para adicionar, trocar ou remover seu áudio.
- Você pode configurar vários botões em sequência.
- Clique em **Salvar configuração** para gravar as alterações no IndexedDB e bloquear novamente a edição.
- A reprodução dos sons continua disponível normalmente fora do modo de configuração.

Projeto estático pronto para GitHub e Vercel.

## Exibição
- No modo normal, somente botões que possuem áudio são exibidos.
- No modo Configurar, todos os 50 botões aparecem para permitir adicionar novos sons.
